# 澤福工單欄位與計價需求

來源：業者提供的手寫欄位表（2026-11-25 收到）。狀態：新增需求，尚未完整實作。紅字為示例，不是預設工單資料。

| 區塊 | 員工需能記錄的內容 |
| --- | --- |
| 訂單 | 訂單日期、客戶名稱、印件名稱 |
| 入紙種類 | 原紙尺寸、紙種、紙磅。例如 31 × 43 英寸、120g 雪銅。原紙尺寸與印刷尺寸分開。 |
| 入紙數量 | 支援「令＋零張」，保留原始單位。依已確認的裁別規則，3 令＋100 張在菊全開為 1,600 張，在 2K 為 3,100 張。 |
| 版材 | 新版、改版、再版、換版，能表達部分換版。 |
| 印刷 | 印刷尺寸（可用尺寸或廠內稱呼）、印刷實數及單位、放損、完成數量、台數、印刷顏色。例：1,250 車＋50 放損；完成數量可手寫於紙單，再由員工核對登錄。 |
| 後加工 | 後加工廠、交期；依來源保留後站或送達指示。 |
| 費用 | 單價 × 計價數量 ×（正面色數＋反面色數）。業者示例：100 元 × 10 令 ×（2＋2）＝ 4,000 元。 |

## 驗收與待釐清

- 入紙量、印刷實數、放損、完成數量與計價數量可分別保存及讀回，不能用其中一個值覆寫其他數量。
- 辨識草稿及人工填單應能保留紙本單位；缺少完成數量或計價數量時，留待員工填寫。
- 計價範例須可重現。待業者確認 4,000 元是印工或整單應收，以及它與既有紙錢、版費欄位的關係，再決定如何計入結算單。
